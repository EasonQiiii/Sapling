## 详细说明

### 1. 统计与概率跨学段 ID 冲突（阻断）

同一 ID 在小学与初中指向不同知识对象，例如：

- `D1-01` 小学=数据分类 / 初中=总体、个体、样本与样本容量
- `D1-05` 小学=折线统计图 / 初中=平均数、中位数与众数
- `D2-03` 小学=可能性大小的判断 / 初中=等可能事件与概率

这不是“进阶重复”，而是 **命名空间崩溃**。

### 2. 正比例/反比例

2022 小学课标仅明确“成正比的量”，反比例系统学习在初中函数。B5 模块自身 policy 已承认这一点，但知识点仍完整存在——允许作为教材拓展，不得标成2022小学明确要求。

### 3. 等式与方程

B3 放在小学目录，但 mapping 写明主要在第四学段。与 B7 并行时，必须有进阶映射表，否则题库会在小学点与初中点之间漂移。

### 4. 跨模块能力重复

小学/初中 `D-CAP-01..03` 同号不同义，属于能力层 ID 冲突，需与知识点 ID 一并纳入命名空间治理。
