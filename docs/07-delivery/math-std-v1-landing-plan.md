# math.std.v1 对策落地计划

**决策：** D-033、**D-034**（G1 / S1 / M1 / D1 / P1）  
**状态：** 计划已确认，**暂不录入数据库、不写种子**（待产品指令「开始执行」）  
**目标版号：** `math.std.v1`

## 首版是什么 / 不是什么

| 是 | 不是 |
|---|---|
| 小学三学段 × 四大领域【内容要求】**全条款**节点 | 学业质量、教学提示/建议混入节点 |
| 人教版教材章–节**映射** | 用教材章节替换标准节点身份 |
| 依赖边仅 **CANDIDATE** | 已认证先修 / 正式学习路径所用依赖 |
| 官方课标对照录入 + 产品签核 | 自编树、商业题库、AI 独立认定 |
| 挂不上的题记 **UNMAPPED** | 为闭环临时拆自定义子点 |

## 阶段（执行令下达后才做）

### Phase 0 — 准备（只读，无库写入）

1. 取得教育部《义务教育数学课程标准（2022年版）》官方文本（PDF/可核对文本）；记录版次与获取路径。  
2. 划定录入范围清单：学段一～三 ×（数与代数 / 图形与几何 / 统计与概率 / 综合与实践）下全部【内容要求】条款；排除学业质量与教学提示。  
3. 打开 [国家中小学智慧教育平台·教材](https://basic.smartedu.cn/tchMaterial)，确认人教版小学数学各册入口（登录后），建「册 → contentId/册名」登记表（映射用，不当标准权威）。  
4. 冻结字段契约草稿（文档层）：标准节点、教材映射、依赖候选、UNMAPPED 记录、`catalog_edition` 清单。

**出口：** 条款清点表 + 人教册清单 + 字段契约；产品确认「可开始 Phase 1」。

### Phase 1 — 标准节点录入（P1，文档/工作表优先）

1. 逐条录入：学段、领域、主题、条款标题/摘要、`curriculum_ref`（页码或官方编号路径）、原文摘录指针或校验摘要。  
2. 双人/两轮核对（至少：录入者 ≠ 抽检者；或产品抽检 100% 父主题结构 + 约定比例条款）。  
3. 产出 `math.std.v1` **节点清单文件**（建议 `docs/03-domain-model/releases/math.std.v1/nodes.md` 或 CSV；**不是** migration seed，除非另有执行令）。  
4. 产品负责人签核：节点集完整覆盖 S1、无教学建议混入、无自定义子点。

**出口：** 签核记录 + 节点清单哈希/版本标签。

### Phase 2 — 人教映射（M1）

1. 按册整理章–节目录（来源：智慧教育平台教材）。  
2. 章/节 → 一个或多个标准节点（多对多允许）；记录映射版本 `math.pep.map.v1`（名称可调）。  
3. 映射变更规则：教材改版 → **新映射版本**；标准节点 ID **不变**（D-034 约束 2）。  
4. 无法映射的章节记原因；不倒逼拆标准点。

**出口：** 映射表 + 来源册登记；产品签核映射版。

### Phase 3 — 依赖候选（D1）

1. 允许 AI/教研提出先修/相关边 → 一律 `RelationStatus=CANDIDATE`，带来源与证据字段。  
2. **硬约束：** 运行时学习路径、干预排序、掌握前提 **不得读取** CANDIDATE 边（D-034 约束 3）。  
3. 首版发布包可附候选边文件，但发布说明写明「未认证」。  
4. 零 PUBLISHED 依赖边。

**出口：** 候选边清单（可空）+ 运行时禁用声明写入设计/适配层备注。

### Phase 4 — UNMAPPED 与闭环衔接

1. 诊断/归并挂点：优先标准节点；失败 → `UNMAPPED` 事件/记录（题 ID、证据、尝试过的 ref）。  
2. 定期评审 UNMAPPED：只收集拆点需求证据；**本版不拆子点**（D-034 约束 1）。  
3. INVALID 自编 42 点种子：保持 INVALID；执行入库时**不得**升格为 `math.std.v1`。

### Phase 5 — 发布包与（可选）入库

仅当产品明确「允许入库」：

1. 发布说明：`math.std.v1` 定义（同 D-034）。  
2. 可执行 seed/migration **另开变更**，与结构 smoke 的 INVALID 种子隔离路径（如 `database/seeds/releases/math.std.v1/`）。  
3. 回滚：撤编本版或回退上一签核哈希（若无上一正式版则仅撤编）。

**当前：Phase 5 默认关闭。**

- [ ] 无自定义子点；UNMAPPED 流程已定义  
- [ ] 产品签核人、日期、文本来源版次已记录  
- [ ] 未把第三方开源图/商业题库标为权威  

## 明确不在本计划内

- 初中条款（学段四）— 后续 edition  
- 多教材版本并行映射  
- PUBLISHED 依赖认证流程的完整运营手册（可另开 U）  
- 数据库 Migration 结构变更（除非字段缺口另开决策）
