# 跨模块协作原则

1. 业务请求走明确接口。  
2. 事实发生后通过 Event 通知。  
3. Event 只通知事实，不是命令。  
4. Event ID 唯一；接收方必须幂等。  
5. 同步接口用于需要明确受理结果的请求。  
6. 不直接跨模块读库。  
7. 不要求每个 Engine 独立数据库。  
8. 跨领域请求使用幂等 ID、异步 Event、查询恢复。  
9. 不要求多领域共享一个数据库事务。  
10. Event 需考虑重复、延迟、乱序。  
11. 保留 OccurredAt、RecordedAt、EventSequence、EventRelation。  
12. 不建立全系统统一事件顺序。  
13. 跨领域批量允许部分成功，逐项记录。  
14. 各对象独立管理生命周期。
