# 闭环内 Decision 权限（P1）

**决策：** D-013、D-006、D-028、D-031；计划默认「练习自动」  

## 学自 / 搬运 / 自研

| | 内容 |
|---|---|
| **学自** | 规则引擎分级授权；ITS 自动选题；家庭产品「目标共定」与「练习任务」分离 |
| **搬运** | 三级权限：自动 / 建议待确认 / 授权决策 |
| **自研** | 钉到本闭环步骤的默认值 |

## 默认权限表（写死）

| 决策类型 | 权限 | 说明 |
|---|---|---|
| Finding→KI 归并 | **自动** | D-028 / D-031 |
| 基于 KI 生成下一步练习建议并启动薄干预 | **自动** | 不等人点选 |
| KnowledgeState 更新 | **自动** | 规则 + OCC |
| 成长目标 Vision/Growth 订立或改方向 | **授权（家长+孩子）** | D-006；V1 缓建 Goal 表，预留 |
| 删除家庭数据 / 隐私高风险 | **授权** | U-014 |
| OCR 低置信确认 | **人可参与** | 入口质量，非认知裁判 |

## DecisionRecord

自动类仍写 DecisionRecord + Candidate + Selection（先记录再执行）；`Authority=AUTO`。  
不因「自动」跳过审计对象。
