# OCR 与人机边界（P0）

**决策：** D-001（纸质优先）、D-028（归并不靠人）、D-030（搬运 OCR）  
**状态：** 产品边界澄清 v0  

## 学自 / 搬运 / 自研

| | 内容 |
|---|---|
| **学自** | 文档理解/OCR 流水线常规：识别 → 置信度 → 人工复核不确定项；开源引擎（PaddleOCR 等） |
| **搬运** | **适配层**接引擎；低置信进入确认队列；确认前不参与归因 |
| **自研** | 哪些步骤禁止成为「业务闸门」的产品划分（见下表） |

## 允许的人参与（入口质量，不是业务裁判）

| 步骤 | 人可以做什么 | 说明 |
|---|---|---|
| 拍照上传 | 家长/孩子上传 | 必要输入 |
| OCR 低置信确认/校正 | 校正识别文字/题界 | **可选加速**；长期应提高自动率 |
| 成长目标 | 家长与孩子共定（D-006） | 与判题/归并分离 |

## 禁止作为必经闸门（系统自动）

| 步骤 | 要求 |
|---|---|
| Finding 生成后的 KI 归并 | 自动（D-028） |
| 练习建议/薄干预生成 | 默认自动；策略见 Decision 权限（P1） |
| 掌握度 State 更新 | 规则自动；依据可追溯 |

## 原则

- 「少依赖人」≠「OCR 永远零确认」；**依赖人的预算花在信号入口，不花在认知裁判。**  
- 引擎可换；产品只依赖适配层接口（U-001：选型可后定，接口先定）。

## 适配层最低接口（搬运点）

`recognize(pages) → candidates + confidence`  
`apply_correction(candidate_id, patch) → new Evidence (CORRECTED_FROM)`  
不在此自研识别模型。
