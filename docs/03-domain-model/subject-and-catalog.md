# 学段 · 科目 · 知识目录（P0）

**决策：** D-029、D-030、**D-033**（2026-11-13 方案 C）  
**状态：** 来源架构已确认；标准目录首版内容尚未按 D-033 发布  

## 一句话

课程标准定义知识体系的基准，教材负责映射教学内容，教研资料补充关系，真实题目验证体系，AI 辅助整理但不拥有最终认定权。

## 学自 / 搬运 / 自研

| | 内容 |
|---|---|
| **学自** | 教育部《义务教育课程标准（2022年版）》内容组织；正式教材章–节结构；教研中的依赖/先修表述 |
| **搬运** | 课标【内容要求】→ 标准知识节点与 `curriculum_ref`；教材 → 年级/章节映射；依赖边仅候选直至验证发布 |
| **自研** | 本系统的版本、候选/发布状态、证据与回滚机制；**不**发明替代课标的权威内容 |

## 两层对象（不得混存）

| 层 | 含义 | 谁拥有 |
|---|---|---|
| **标准知识体系** | 公共基准目录（节点、可选正式依赖） | 系统/发布版本；全家庭共用同一发布版 |
| **个人知识地图** | 孩子对标准节点的掌握/问题状态 | 学习者（KnowledgeState、KnowledgeIssue 等） |

禁止把个人掌握度写进标准目录表，也禁止为每个孩子复制一套「私有课标」。

## 来源分工（D-033）

| 来源 | 用途 | 定位 |
|---|---|---|
| 课标 2022 | 权威基准 | 核心 |
| 正式教材（中小学知识平台等） | 年级/章节/教学内容映射 | 教学映射 |
| 教师用书、教研资料 | 关系补充 | 辅助 |
| 真实作业、题目 | 划分是否合理 | 验证 |
| AI 提取 | 整理与候选关系 | 无独立认证权 |

## 依赖关系生命周期

```
propose (AI/教研) → candidate（带来源与证据）
  → review/validate（题目/教学验证）
  → publish（新版本） / reject
  → 可 rollback 到既有发布版
```

未 publish 的边不得驱动正式干预前提假设为「已确认先修」。

## 逻辑维度

| 字段/对象 | 含义 | 备注 |
|---|---|---|
| `SchoolStage` | 学段 | PRIMARY / JUNIOR_SECONDARY … |
| `SubjectCode` | 科目 | 先 MATH |
| `KnowledgePoint` | **标准**目录节点 | 锚定课标；稳定 ID |
| `curriculum_ref` | 课标条目引用 | 权威锚，必填方向（D-033） |
| 教材映射 | 教材版别、册、章、节、年级 | 映射表/扩展，非第二权威 |
| 依赖边 | candidate \| published | 版本化 |

## 明确不做

- 不把某一商业题库/开源第三方图直接标为权威标准体系。  
- 不声称本仓库已拥有「新权威知识库」。  
- 不把 AI 生成树未经验证发布。
