# 项目概述

**项目名称：** Family Learning OS — 家庭 AI 学习管家  
**对象：** 小学阶段，重点四至六年级

## 目标

帮助孩子形成可迁移的底层学习能力，而非仅提高某次作业或考试成绩。

**核心能力：** 独立学习、系统思维、批判性思考、创造力、自主探索、自我管理。

最终希望孩子离开 AI 后，仍然知道如何学习和解决问题。

## 核心学习闭环

发现问题 → 理解问题 → 拆解问题 → 探索解决 → 验证反思

AI 扮演**学习方法教练**，而不是代替孩子完成任务的工具。

## 产品定位

- 适配孩子现有学习行为
- 优先支持纸质作业
- 通过长期证据了解知识掌握与思维能力
- 根据真实问题安排学习干预
- 随成长逐步降低 AI 提示强度
- 逐步建立自主学习能力
