# Glossary

| 术语 | 含义 |
|---|---|
| LearningTask | 业务学习任务 |
| WorkflowRun | 一次流程执行实例（≠ Task） |
| Question | 稳定题目身份 |
| QuestionVersion | 题目内容不可变版本 |
| TaskQuestion | 任务中的题目实例，固定某 QuestionVersion |
| LearningResponse | 一次真实作答 |
| Evidence | 学习事实证据（内容不可覆盖） |
| LearningEvent | 业务事实事件（不是命令） |
| Diagnosis | 一次诊断活动 |
| Finding | 不可变诊断判断 |
| FindingValidity | Finding 有效性追加记录 |
| KnowledgeIssue | 长期知识问题 |
| LearningState | 当前状态快照（四类） |
| StateRevision | 状态不可变修订 |
| DecisionRecord | 一次决策记录 |
| LearningIntervention | 学习干预（≠ Workflow） |
| LDSM | Learning Data and State Management |
| ExecutionRequestID | 请求幂等身份（C-03 / D-022） |
| RECONSTRUCTED | 非原文恢复、按基线重建的内容标记 |
| 学段范围 | 中小学（D-029）；非仅小学四至六年级 |
| 学科范围 | 全科目标；落地先做数学（D-029） |
