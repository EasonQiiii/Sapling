# items/README.md — 题目清单记录规则

这个目录存放从教材里整理出来的题目清单。每本书一个 YAML 文件，与 knowledge-spine 并列，不影响 spine。

## 这份清单对应哪本书

苏教版（江苏凤凰教育出版社）《义务教育教科书·数学五年级上册》，根据 2022 年版课程标准修订，2026 年秋季启用。逐页核对以国家中小学智慧教育平台上的电子课本为准（本清单核对的是平台电子课本 PDF，ISBN 978-7-5743-2532-6，140 页）。

公开目录对上了：图形的运动、统计表和条形统计图（二）、多边形的面积、小数乘法和除法（一）、可能性、因数与倍数、用字母表示数量关系（一）、观察物体（三）、期末复习，以及综合与实践「图案的还原」「绿色出行」「农田收入调查」「钉子板上的多边形」。

## 收什么

- 只收**练习性题目**，以课本栏目为准：试一试、练一练、单元练习（含「练习一」到「练习十四」、「整理与练习」「练习与应用」「探索与实践」）、期末复习的「练习与应用」「探索与实践」、四个综合与实践栏目里的操作题。
- **依赖教材未转写数据的题不收**：题干或图形缺少插图、图形、表格或算式清单中的数据，离开教材无法作答的，删去（教材题偏教学，正式题需自包含）。
- **例题不收**。例题里的讲解、对话框、「回顾一下」这类教学过程也不收。
- 「回顾与整理」「评价与反思」「你知道吗」「动手做」这类回顾、自评、拓展栏目不收。
- 大题的第（1）（2）（3）问**拆开，一问一行**；没编号的多个小填空算一行。
- 综合与实践里的题照收；纯活动（讨论、倡议书、自评、互评）对不上知识点的，留空并写原因。
- 这册没有遇到标「选学」的题目；如果以后遇到，照收并标明选学。

## 不收哪些内容

这册书里没有的内容不收：小数乘小数、小数除以小数、简易方程、用数对确定位置。spine 里小数乘小数、小数除以小数、解方程的编号不用。

## 每一行记什么

- **id**：前缀跟文件走（教材册用 G5V1- 等），G5V1-序号只做行标识。
- **source**：题从哪来。分两种写法，用 origin 区分：
  - `origin: textbook`：教材题，写单元、页码、栏目、题号（版本和册次写在文件头）。
  - `origin: self` / `external`：自编、改编或第三方题库题，写来源说明（谁出的、改编自什么、依据哪些知识点），页码和栏目留空。
  出处只说明题从哪来，**不参与排序**。
- **task**：用我们自己的话写这道题在要求学生做什么。**不抄教材原文。**
- **kp_main**：主要知识点，取自已定稿 spine YAML 里的一个编号。拿不准或没有对应编号时留空（null），并在 kp_reason 写一句原因。
- **kp_other**：同时还要用到的知识点，零个或多个编号。
- **thinking**：思维方式，五档，就高不就低：
  1. 认出来就做
  2. 按步骤做
  3. 先选方法或先把情境翻译成数学关系
  4. 还要说明理由
  5. 自己把几个关系串起来

  知识点留空的题（纯活动、开放活动），thinking 也留空，只保留 kp_reason。

知识点编号只从 knowledge-spine/小学/数学/ 的 14 个已定稿 YAML 里选，不新造编号。本册各单元挂的文件：

- 图形的运动 → 图形与几何-图形的位置与运动.yaml（C2）
- 统计表和条形统计图、可能性 → 统计与概率.yaml（D1、D2）
- 多边形的面积、公顷和平方千米、观察物体 → 图形与几何-图形的认识与测量.yaml（C1）
- 小数乘整数、小数除以整数、因数与倍数 → 数与运算.yaml（A）
- 用字母表示数量关系 → 数量关系-用字母表示数.yaml（B1）；只有题面明确在感知等式性质/等量推理时才用到 等式与方程.yaml 里的 B3-01、B3-03，解方程（B3-05）不用
- 个别应用题会引用 数量关系-常见数量关系.yaml（B2-04 总价单价数量、B2-05 路程速度时间）作次要知识点

## 图形数据

图形题独立成题：题目给出的图记在 `figure` 字段里，用数据画图，不贴课本截图。

- **坐标系**：方格纸左下角为原点，横轴 x 向右，纵轴 y 向上，一格为 1。坐标可以为负数（如 G5V1-041 左下拼图用到 y=-2）。
- **记交叉点，不记涂色格子**：只记格点（顶点、端点、标注点）的坐标。
- **个别无方格的图**（钟面、直线、正多边形示意图等），坐标只表示相对位置，在 figure.note 里注明。
- 三种 type：
  - `points`：点、线段、多边形（本册 001–046 全部使用）。`shapes` 里每个元素有 `name` 和 `points`；需要时另加 `labels`（字母标注的位置）、`circles`（圆：`center` + `radius`）、`axis`（对称轴：`kind` 竖直/水平 + `x` 或 `y`）、`note`。
  - `heights`：正方体搭物体，从上看每格的层数。本册未使用，格式约定为：`rows` 为二维数组，从上到下逐行记录，每个数字表示该格叠的正方体层数，0 表示该格没有正方体。
  - `table`：统计数据。本册未使用，格式约定为：`columns` 为表头数组，`rows` 为逐行数据数组。
- **figure 只放题目给出的图形**；学生要自己画或设计的（如 G5V1-026 画对称四边形），figure 为 null。
- **answer** 与 figure 使用同一数据格式（能画出结果的，如平移、旋转、补全后的图形顶点），或写成文字（数值、结论、运动方式）。
- **answer_note**：开放题必写，说明完成标准；不编标准图。

## 排序怎么排

文件本身按课本顺序排：页码从小到大；同一页按栏目（试一试、练一练、单元练习、整理与练习、练习与应用、探索与实践、综合与实践）；同一栏目按题号，未编号的题排在该栏目最后。

使用时再算难度，只看两样，现算、不写进文件、也不另存难度分：

1. 先按思维方式从低到高（1→5）；
2. 同一档里，按用到的知识点总个数从少到多（主要知识点算 1 个）。

知识点为空的题不参与这个排序。抽查方法：同一个主要知识点下面，「认出来就做」的题应该排在「要说明理由」的题前面；发现反了，只改这道题的思维方式或知识点标注，不改 spine。

## 不做什么

- 不记星级，不记别人题库的标签，不把单元名当成题的身份（单元名只出现在出处里）。
- 不改 knowledge-spine/MATH_STD_V1_FREEZE.md 和 14 个已定稿 YAML。
- 不把清单写进数据库；这一册顺了再决定下一册。

## 非教材题怎么放

教材题一册一个文件（如 `sujiao-g5-vol1.yaml`），不按年级、按册另建自编文件。以后有自编或外面的题，统一新建一个 `items/extra.yaml` 放进去：

- 来源用 source 里的 origin 区分：`origin: self`（自编、改编）或 `origin: external`（第三方题库），并写清来源说明；页码和栏目留空。
- 知识点、思维方式等标注规则与教材题完全相同；使用时排序也一样现算。
- id 前缀跟文件走，与教材文件不撞号。
- 文件名不当题的身份——身份就是那一行的字段，合并、抽题、迁移都靠字段现算。
- 现在还没有非教材题，这次不建空文件，等真的有题了再建。
