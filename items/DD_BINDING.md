# 题目绑定诊断切面（`dd_main`）

> 依据：spine `assessment_binding`——每道题应尽可能绑定具体诊断维度，用于做对/做错时的认知归因。  
> 生效：2026-11-21 起试点；全库回填完成前字段可省略。

## 字段

| 字段 | 必填 | 含义 |
|---|---|---|
| `kp_main` | 有知识点时必填 | 主考知识点 |
| `kp_other` | 否 | 做题顺带用到的知识点 |
| `dd_main` | 试点期可选 | 本题实际测量的主诊断切面 |
| `thinking` | 有知识点时必填 | 思维档，用于排序，不作诊断归因 |

## 取值规则

1. `dd_main` 必须落在 `kp_main` 的 `diagnostic_dimensions` 内。
2. 切面在 spine 中若是 `{id, name}` 对象，题库写 **id**（稳定键）。
3. 切面在 spine 中若是纯字符串（无 id），题库写 **该中文字符串原文**（逐字一致）。
4. `kp_main` 为 null 时不得写 `dd_main`。
5. 不从 LO/DD 的辨析措辞派生反例题（`IC-DERIVE-01`）；切面只用于归因绑定。

## 回填顺序

1. 新题（S-B07 起）出题时同步填写。
2. 已有自编题按 KP 分批回填；先覆盖 B1/B2/B4/B5 等诊断缺口相关点。
3. 教材题按需回填，不阻塞校验。
